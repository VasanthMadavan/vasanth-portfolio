# Vasanth Madavan Portfolio

Lightweight static portfolio designed for Cloudflare Pages.

## Deploy to Cloudflare Pages

1. Push this folder to a new GitHub repository.
2. In Cloudflare Pages, choose **Create a project** → connect that repository.
3. Use these settings:
   - Framework preset: **None**
   - Build command: **leave empty**
   - Build output directory: **dist**
4. Click **Save and Deploy**.

The deployed site has no environment variables and no build dependencies.
